# Sonali-Portfolio

Personal UX/UI & Digital Product Design portfolio website for **Sonali Nayak**.

## 🌟 Overview
A modern, responsive, high-fidelity personal portfolio web application crafted with React 18, Vite, and modular CSS design tokens following strict typography and aesthetic guidelines.

## 🚀 Tech Stack
- **Framework**: React 18
- **Bundler**: Vite 6
- **Styling**: Vanilla CSS Design Tokens (`src/styles/tokens.css`, `src/styles/index.css`)
- **Typography**: Playfair Display (Editorial Serif) & Plus Jakarta Sans
- **Deployment**: Vercel ready

## 🛠️ Project Structure
```
Personal Portfolio/
├── public/assets/         # Static assets (images, resumes, icons)
├── src/
│   ├── assets/            # Component visual assets
│   ├── components/        # React modular sections
│   │   ├── Header.jsx     # Navigation bar & brand mark
│   │   ├── Hero.jsx       # Hero headline, bio, CTAs & 3D tilt
│   │   ├── ScrollCue.jsx   # Interactive scroll explore cue
│   │   ├── WhatIDo.jsx    # Capabilities & intentional design
│   │   ├── HowIWork.jsx   # 5-step methodology (Understand -> Refine)
│   │   ├── Work.jsx       # Selected case studies container
│   │   ├── ProjectCard.jsx# Project case study cards
│   │   ├── ExperienceSkills.jsx # Roles & toolkit pills
│   │   ├── AboutMe.jsx    # Personal backstory, art & sketch cards
│   │   ├── PhilosophyQuote.jsx  # Ambient design philosophy banner
│   │   └── Footer.jsx     # Conversational contact footer & socials
│   ├── styles/
│   │   ├── tokens.css     # CSS custom properties design tokens
│   │   └── index.css      # Core styles, responsive layouts & micro-animations
│   ├── App.jsx            # Application root
│   └── main.jsx           # React DOM root entry
├── index.html             # HTML5 entry with Google Fonts
└── vite.config.js         # Vite build configuration
```

## 💻 Local Development

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start development server**:
   ```bash
   npm run dev
   ```

3. **Build for production**:
   ```bash
   npm run build
   ```
